# 🐱 API Consumer CatFact

Este repositório contém uma aplicação de consola desenvolvida em **C#** (.NET) como requisito para a disciplina de Usabilidade, Dev. Web, Mobile e Jogos, orientada pelo Professor Daniel Henrique Matos de Paiva[cite: 22].

## 🎯 Objetivo
O principal objetivo do algoritmo é consumir o endpoint `https://catfact.ninja/fact` e processar o retorno em formato JSON para extrair a propriedade `fact`, que representa uma curiosidade aleatória sobre felinos[cite: 22].

## 🚀 Como Executar
Certifique-se de que tem o **.NET SDK** instalado no seu computador. Abra o terminal na pasta raiz do repositório e execute o seguinte comando:

```bash
dotnet run
